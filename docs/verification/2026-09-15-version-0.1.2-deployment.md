**Do not blindly roll the backend back to the prior release.** It predates
account-deletion tombstones and may permit access that the new version must deny.
Inspect accepted deletion requests and migration compatibility before any rollback;
prefer a forward fix. Do not restore an old database dump as routine application
rollback or overwrite newer user data. Never uninstall an app to troubleshoot an
update unless its local recordings and state have been considered first.
